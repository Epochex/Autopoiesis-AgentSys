# 两项演示与验收

在项目目录使用 root 执行，网关须已启动。两个脚本仅创建和操作专用
`autopoiesis-acceptance-*` 服务，拒绝覆盖同名已有服务。结束后清理服务，保留调查、记忆版本和变更回执。

## 答辩演示

```bash
cd /data/Autopoiesis-AgentSys
./scripts/demo_self_healing.py
./scripts/demo_memory_trajectory.py
```

两个命令依次执行。前端打开“待处理事件 → 演示与验收”。

自愈用例：点击“处置轨迹”，观察连续两次故障检测、变更前状态和 Diff、
仅匹配本次服务的一次性授权、重启、7 次回读。Diff 预览保留 15 秒，观察采样间隔 5 秒。
脚本负责执行，观看时无需手动审批；生产设备写入开关保持原值。
服务重启属于瞬时动作，无法撤销已经发生的重启，失败将留下人工处理回执。

记忆用例：点击“记忆与轨迹”，观察关闭记忆和开启记忆的两轮真实调查，
查看分层记忆节点、上下文包、工作集变化与长轨迹回放。
“完整上下文”包含保存的调查上下文快照；模型完整输入仅在实际模型调用被记录时显示。
本用例的已确认服务故障路径使用确定性检查决策。

验收对比两轮实际执行检查数，并单独记录候选检查数和请求耗时。
候选 4 项、执行 1 项与两轮实际检查量差异分别计量；耗时受当前机器负载影响。
长轨迹统计与后继状态预测用于回放分析，预测保留为观察用途。

## 快速测试

```bash
./scripts/demo_self_healing.py --test
./scripts/demo_memory_trajectory.py --test
```

使用同一条真实检测、执行和记忆路径。省去观看等待，自愈改为 1 秒间隔、4 次回读。
全部断言通过返回 0；失败返回非零并保存失败记录。失败历史保留，前端显示最新进展。
自愈失败条件包括恢复失败、保护检查失败、回读不足；记忆失败条件包括未减少实际检查、
缺少上下文快照、缺少工作集更新或缺少轨迹活动。
